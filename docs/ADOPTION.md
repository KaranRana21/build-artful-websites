# Measuring adoption honestly

This public repository is early-stage. Do not confuse documentation commits, generated downloads, or self-installs with third-party adoption.

## What counts as useful evidence

- Public issues from independent developers with reproducible examples.
- Independently authored PRs.
- Genuine mentions/installations in public projects, with consent.
- Package/skill directory installation counts when verified by provider.
- Repeat contributions and documented maintainer support activity.
- Real feedback from people using skill on actual websites.

## What not to claim

- Stars or installs that were not observed.
- Self-installed trials as third-party demand.
- Private projects as public ecosystem adoption.
- AI-generated examples as client work.
- A release label as ongoing maintenance history.
- Being officially affiliated with OpenAI, Codex, or skills.sh.

## Learning loop

After real usage, collect optional anonymized feedback on clarity, fit, design distinctiveness, mobile/accessibility outcomes, and agent compatibility. Link evidence from public issue or PR; redact private client information.

Record dates and source of any metric when applying for grants or maintainer programs.
