# Example: creative portfolio

**Scenario (fictional example):** independent multidisciplinary designer presenting selected projects.

## Prompt

Use `build-artful-websites`. Inspect actual portfolio assets and permitted use. Define editorial composition, typographic hierarchy, and project sequencing before picking effects. Write `DESIGN.md`. Build strong static project indexes with accessible category filters and accurate credits. Consider spatial gallery or subtle GSAP choreography only if it makes navigation and storytelling better; use advanced integration protocol for performance cleanup and touch/reduced-motion fallbacks. Avoid fake awards, client logos, and self-congratulatory testimonials.

## Acceptance criteria

- Every project has real or clearly labeled concept work.
- Direct deep links to projects work.
- Keyboard and mobile users can browse every project.
- WebGL unavailability does not break portfolio.
- Distinctive motion never obstructs project understanding.
