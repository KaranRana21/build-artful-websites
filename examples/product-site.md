# Example: product marketing website

**Scenario (fictional example):** software product seeking demo bookings.

## Prompt

Use `build-artful-websites`. Inspect real product UI, pricing, feature availability, existing design system, and target audience. Write `DESIGN.md` with trust-first art direction. Explain use cases using actual screenshots and concrete outcomes; avoid generic SaaS three-card formula and unsupported metrics. Implement clear demo CTA and understandable forms. Motion should support product explanation, not block reading. Ensure accessible form errors and confirmation, valid metadata, performance, and privacy-respecting data handling.

## Acceptance criteria

- Visitor understands product, intended user, and next action.
- Screenshots, integrations, promises, and numbers are verifiable.
- Demo form validates, handles errors, and uses secure submission.
- Excellent keyboard/touch support and reduced-motion behavior.
- Production SEO and performance checked with real tools when available.
